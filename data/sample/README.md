# data/sample/

Generated synthetic project data for the fictional **Payments Platform** project.
Produced by `scripts/generate_dataset.py` (step 3) and committed so the whole
team can run the app in mock mode with no setup.

Expected files once the generator exists:

| File | Contents |
| --- | --- |
| `people.json` | The 4 team members (Ravi, Priya, Arjun, Meera) |
| `emails.json` | Email threads |
| `chats.json` | Teams-style chat messages |
| `tickets.json` | Incident / work tickets |
| `wiki.json` | Wiki / doc pages |
| `commits.json` | Git commit records |

Note: `data/graph.json` and `data/.state/` are runtime output and are gitignored.
